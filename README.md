# -GameVerse-SQL-Analytics-Project
SQL data analytics project analyzing player behavior, revenue, sessions, and business KPIs for GameVerseDB.
📖 Project OverviewThis repository contains a comprehensive Gaming Analytics Database (GameVerseDB) designed to manage and analyze gaming platform data. It includes data across various aspects such as players, games, game sessions, purchases, payments, and achievements. This project is built to evaluate business KPIs (Key Performance Indicators) and player behavior using SQL queries.   🗄️ Database Schema & TablesThe database is built on the following main tables:   Players: Stores player information (Name, Username, Email, Age, Country, JoinDate, Level).Games: Stores game details (Genre, Platform, Release Year, Developer, Rating, Price).GameSessions: Tracks how long players played, along with their score and device details.Purchases: Details in-game purchases and items bought.Payments: Tracks payment methods and transaction status.Achievements: Records achievements and badges unlocked by players.📊 Key SQL Analysis & KPIsThis project executes SQL queries to solve key business problems:   Total Registered Players: Calculates the total number of registered players in the system.   Total Revenue: Calculates total revenue earned from in-game player purchases.   Active Players: Counts distinct players who have played at least one game session.   Average Session Duration: Calculates the average duration of all recorded game sessions in minutes.   Highest Spending Player: Finds the player with the highest total spending using inner joins and grouping.   Most Popular Game: Identifies the most popular game based on total sessions played.   Country-wise Revenue: Computes total purchase revenue generated by players from each country.   Top Players Ranking: Ranks the top 5 players based on their total score across all sessions using CTEs and DENSE_RANK().   🛠️ Technologies UsedSQL (Relational Database Management)
