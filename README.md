# -GameVerse-SQL-Analytics-Project
SQL data analytics project analyzing player behavior, revenue, sessions, and business KPIs for GameVerseDB.
# Project Overview
This repository contains a comprehensive Gaming Analytics Database (GameVerseDB) designed to manage and analyze gaming platform data. It includes data across various aspects such as players, games, game sessions, purchases, payments, and achievements. This project is built to evaluate business KPIs (Key Performance Indicators) and player behavior using SQL queries.
